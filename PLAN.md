# План: три проекта без бэкенда

Допущения (поправь, если неверно):
- Первый рынок: **Россия**, язык интерфейса: русский, валюта ₽. Дальше можно клонировать под КЗ/BY.
- Нет API нейросетей, нет платного хостинга. Всё работает в браузере, сайты статические на Cloudflare Pages (бесплатно, безлимитный трафик).
- Один разработчик, часть времени.

---

## 0. Общая архитектура

Монорепозиторий (pnpm workspaces):

```
temka/
  apps/
    calc/       # Проект 1: калькуляторы (Astro, SEO)
    tests/      # Проект 2: генератор тестов (Vite + Preact/Svelte SPA)
    trainer/    # Проект 3: тренажёры (Vite + Preact/Svelte PWA)
  packages/
    ui/         # общие кнопки, формы, тема, верстка
    core/       # общие утилиты: форматирование чисел, хранилище, аналитика
  PLAN.md
```

Общие решения:
- **Язык:** TypeScript везде.
- **Хранение данных:** localStorage / IndexedDB (библиотека `idb-keyval`). Данных на сервере нет.
- **Аналитика:** Яндекс.Метрика (бесплатно, для РФ-аудитории обязательна), события целей: «расчёт выполнен», «PDF скачан», «тренировка завершена».
- **Деплой:** GitHub → Cloudflare Pages (автосборка при push). Домены: по одному на проект.
- **Тесты:** Vitest для расчётной логики (критично для калькуляторов).
- **Юридическое:** страница «Политика конфиденциальности» и «Условия», баннер cookie для метрики и рекламы.

Порядок запуска: **1 → 2 → 3**. Причина: калькуляторы быстрее всего дают трафик, генератор тестов даёт платящих, тренажёры требуют больше дизайна.

## Проект 1. Калькуляторы (apps/calc)

### Цель
Сайт-хаб из точных и понятных калькуляторов с поисковым трафиком. Каждый калькулятор это отдельная страница под свой запрос.

### Стек
- **Astro** (статика, лучший SEO и скорость) + острова на Preact для интерактива.
- Расчётная логика вынесена в чистые TS-функции с тестами, без привязки к UI.
- Ставки и лимиты лежат в `data/rates-2026.json` с полем `source` (ссылка на закон/ФНС) и `updatedAt`.

### Калькуляторы MVP (порядок реализации)
1. **Зарплата на руки (НДФЛ)**: прогрессивная шкала НДФЛ (ставки и пороги из конфига), режим «от оклада до выплаты» и обратный «сколько нужно оклада на руки X».
2. **Налог самозанятого (НПД)**: ставки 4% и 6%, годовой лимит дохода, налоговый бонус, прогноз остатка до лимита.
3. **Кредит с досрочным погашением**: аннуитет и дифференцированный, график платежей, выбор «сократить срок» или «уменьшить платёж», экономия на процентах.
4. **Ипотека или аренда**: сравнение по горизонту N лет (первоначальный взнос, ставка, рост цен на жильё, рост аренды, доходность вложений первоначального взноса).
5. **Налоги ИП (УСН доходы 6% / доходы минус расходы 15% и страховые взносы)**: на втором этапе.

Для каждого калькулятора на странице:
- форма расчёта, результат с разбивкой, график (лёгкий, без тяжёлых библиотек, например uPlot);
- блок «Как мы считаем» с формулами и ссылками на закон;
- блок FAQ (5–8 вопросов, разметка `FAQPage` JSON-LD);
- дата актуальности данных («Ставки на ноябрь 2026»);
- кнопка «Скопировать ссылку с параметрами» (состояние в query string, удобно делиться и хорошо для виральности);
- кнопка «Скачать расчёт в PDF» через печатный CSS.

### SEO-структура
- Главная: список калькуляторов по категориям (Налоги, Кредиты, Работа, Недвижимость).
- URL: `/zarplata-na-ruki/`, `/nalog-samozanyatogo/`, `/dosrochnoe-pogashenie-kredita/`, `/ipoteka-ili-arenda/`.
- Для каждой страницы: уникальный `<title>`, description, один H1, `BreadcrumbList`, `SoftwareApplication`/`WebApplication` микроразметка.
- Программные страницы-варианты (после MVP): «зарплата 80 000 на руки», «кредит 1 млн на 5 лет», сетка популярных сумм. Генерируются Astro автоматически. Главное правило: уникальный полезный контент, не дубли.
- Sitemap и robots, подача в Яндекс.Вебмастер и Google Search Console.

### Монетизация
- Рекламная сеть Яндекса (РСЯ) после набора ~1–2 тыс. визитов в день.
- Партнёрские блоки (кредит, ипотека, РКО для ИП) через партнёрские программы банков и агрегаторов, с пометкой «реклама».
- Без регистрации и платной части на старте.

### Этапы
| Неделя | Результат |
|---|---|
| 1 | Каркас Astro, общий layout, `rates-2026.json`, калькулятор зарплаты + тесты |
| 2 | НПД и кредит с досрочным погашением, деплой на Cloudflare Pages, Метрика, Вебмастер |
| 3 | Ипотека/аренда, SEO-разметка, FAQ на всех страницах |
| 4 | Политика, cookie-баннер, прогон Lighthouse (цель 95+), старт индексации |
| 5+ | Калькуляторы ИП, программные страницы, внешние ссылки (Pikabu, vc.ru, Habr, профильные форумы) |

### Риски
- **Устаревание ставок.** Решение: раз в квартал и после каждого закона проходить чек-лист, дата обновления видна пользователю.
- **Ошибка в формуле = потеря доверия.** Решение: тесты на эталонные примеры (сверка с онлайн-калькулятором ФНС и расчётами банков).
- **Высокая конкуренция по общим запросам.** Решение: брать длинный хвост и точные формулировки, опираться на понятность и скорость.

### Метрики успеха
- Через 3 месяца: 100+ страниц в индексе, 500+ визитов в день из поиска.
- Доля пользователей, дошедших до результата расчёта: выше 60%.

## Проект 2. Генератор тестов и карточек для учителей (apps/tests)

### Цель
Учитель за пару минут собирает тест, контрольную или набор карточек и печатает или скачивает PDF с вариантами и листом ответов.

### Стек
- **Vite + Preact (или Svelte)**, SPA с маршрутизацией.
- Данные проекта лежат в IndexedDB, плюс экспорт и импорт JSON-файла (резервная копия, перенос между устройствами без сервера).
- **PDF:** печать через `@media print` и `window.print()` для базового варианта (отличная поддержка кириллицы, ничего не надо встраивать). Для кнопки «Скачать PDF» позже: `pdf-lib` + `@pdf-lib/fontkit` с встроенным шрифтом (PT Sans / Roboto).

### Функции MVP
1. **Редактор вопросов:**
   - типы: один ответ из вариантов, несколько ответов, верно/неверно, короткий ответ, соответствие;
   - поля: текст, варианты, правильный ответ, баллы;
   - картинки к вопросу (хранятся в IndexedDB, вставка из файла или буфера).
2. **Банк вопросов** с тегами (предмет, класс, тема) и поиском.
3. **Сборка теста:** выбрать вопросы вручную или случайные N по тегам.
4. **Варианты:** 1–6 вариантов с перемешиванием вопросов и ответов, у каждого свой ключ.
5. **Вывод:**
   - печатный лист теста (шапка: ФИО, класс, дата, вариант),
   - лист ответов (ключ) для учителя,
   - бланк для проверки с кружками.
6. **Карточки:** лицо/оборот, печать на листе A4 с линиями резки (2×4, 3×3), режим двусторонней печати.
7. **Шаблоны:** заготовки для математики, русского, английского, окружающего мира (30–50 готовых вопросов на старте для быстрого эффекта).

### Позже (v2)
- Онлайн-прохождение теста учеником по ссылке (потребует легкий бэкенд, например Cloudflare Workers + D1; делать только если появится спрос).
- Импорт вопросов из Word/Excel/CSV.
- Общая библиотека шаблонов от пользователей (с модерацией).

### Монетизация
- **Free:** до 3 сохранённых тестов, до 2 вариантов, водяной знак мелким шрифтом на печати.
- **Pro (подписка или разовая покупка):** без ограничений, без знака, банк вопросов, карточки, экспорт.
- Платёжный провайдер выбрать отдельно (учесть, что часть зарубежных сервисов не работает с РФ); лицензия проверяется ключом на клиенте или бесплатным Cloudflare Worker.
- Альтернатива на старте: донаты и Boosty, пока нет платёжки.

### Продвижение
- Сообщества учителей во ВКонтакте и Telegram, форумы и группы «Учителя начальных классов», «Учителя математики».
- Бесплатные готовые тесты как SEO-страницы: «Тест по таблице умножения 3 класс печать», «Карточки английские слова распечатать».
- Публикации на «Педсовет», «Инфоурок» и подобных ресурсах со ссылкой.

### Этапы
| Неделя | Результат |
|---|---|
| 1 | Каркас, модель данных вопроса и теста, хранилище в IndexedDB |
| 2 | Редактор вопросов (3 типа), сборка теста |
| 3 | Печатный вывод с вариантами и ключом |
| 4 | Карточки и печать на A4 |
| 5 | Шаблоны, SEO-страницы с готовыми тестами, деплой |
| 6 | Платная часть, сбор обратной связи от 5–10 учителей |

### Риски
- **Сложная вёрстка печати** (разрывы страниц, шрифты). Решение: тестировать в Chrome, Firefox, Яндекс.Браузере с реальным принтером и «Сохранить как PDF».
- **Потеря данных при очистке браузера.** Решение: напоминание делать экспорт JSON, понятная кнопка резервной копии.
- **Нет онлайн-режима, учителя ждут „как в сервисах“.** Решение: чётко позиционировать как «печатные материалы быстро и приватно».

### Метрики успеха
- 50 учителей создали хотя бы один тест за первый месяц, 10% дошли до Pro.

## Проект 3. Тренажёры (apps/trainer)

### Цель
Серия коротких игровых тренажёров, которые дети и взрослые открывают каждый день (таблица умножения, английские слова, скорость печати). Работает как PWA, в том числе офлайн.

### Стек
- **Vite + Svelte** (или Preact), PWA через `vite-plugin-pwa`.
- Анимации на CSS и Web Animations, звуки через Howler.js (опционально).
- Прогресс хранится в IndexedDB, экспорт и импорт профиля.

### Общий игровой движок (packages/core или внутри приложения)
- **Сессия:** 10 вопросов или 60 секунд.
- **Адаптивность:** алгоритм интервального повторения (простая Leitner-система): ошибки возвращаются чаще, выученное реже.
- **Механики:** серии подряд (стрики), звёзды за сессию, ежедневная цель, значки за достижения.
- **Профиль:** имя, аватар, возможность нескольких профилей на устройстве (для семьи или класса).
- **Режим учителя:** показать таблицу результатов профилей на одном устройстве.

### Тренажёры MVP
1. **Таблица умножения:** выбор таблиц (2–9), режим «найди ответ» и «найди множитель», тайм-атака, ошибки по ячейкам тепловой картой.
2. **Английские слова:** встроенные словари по темам и уровням (A1–B1) со слабыми и сильными словами, режимы: карточки, выбор перевода, написание, прослушивание (Web Speech API `speechSynthesis`, бесплатно и без API).
3. **Скорость печати:** русские и английские тексты, ввод в реальном времени, метрики WPM и точность, подсветка проблемных клавиш и график прогресса.

### Позже
- Деление, сложение/вычитание, дроби.
- Немецкий, испанский словари.
- Загрузка собственного словаря (CSV).
- Классы для учителей (потребует бэкенда).

### Монетизация
- Free с ненавязчивой рекламой (только на экранах между сессиями).
- Pro: без рекламы, все словари, несколько профилей, расширенная статистика.
- Лицензия для школ (пакет для кабинета).

### Продвижение
- SEO: «тренажёр таблицы умножения онлайн», «проверка скорости печати», «учить английские слова онлайн».
- Родительские чаты и учительские сообщества.
- Обмен трафиком с проектом 2: ссылка «Распечатать карточки» из тренажёра и «Потренироваться» из генератора тестов.

### Этапы
| Неделя | Результат |
|---|---|
| 1 | Каркас PWA, профиль и хранилище, игровая сессия |
| 2 | Тренажёр умножения целиком (с интервальным повторением) |
| 3 | Скорость печати |
| 4 | Английские слова (300–500 слов на старте) |
| 5 | Достижения, стрики, офлайн-режим, полировка анимаций |
| 6 | SEO-страницы, деплой, Pro |

### Риски
- **Удержание.** Тренажёр без «крючка» забывают. Решение: ежедневные цели, серия дней, красивая обратная связь.
- **Дизайн для детей.** Решение: крупные элементы, цвета с контрастом, минимум текста.
- **Контент словарей** требует времени. Решение: открытые списки частотных слов с проверкой лицензий.

### Метрики успеха
- Возвраты на 7-й день выше 15%, средняя сессия 3–5 минут.
