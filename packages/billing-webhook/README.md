# Автоматическая выдача ключей Gridika (Yandex Cloud Function)

Этот микро-бэкенд автоматически принимает вебхук об успешной оплате (ЮKassa / Robokassa), криптографически выпускает и подписывает ключ `GRD1-...`, формирует адаптивное HTML-письмо и отправляет его покупателю с почты `info@gridika.ru`.

---

## 🚀 Пошаговое развёртывание в Яндекс Облаке (за 3 минуты)

### Шаг 1. Создание функции в Яндекс Облаке
1. Войдите в консоль: [console.yandex.cloud](https://console.yandex.cloud).
2. В меню слева выберите **Cloud Functions** (Бессерверные функции).
3. Нажмите **«Создать функцию»**:
   * **Имя:** `gridika-billing`
   * Нажмите **«Создать»**.

---

### Шаг 2. Загрузка кода
1. В открывшемся окне функции в блоке **«Среда выполнения»** выберите:
   * **Среда выполнения:** `Node.js 20` или `Node.js 18`
   * **Точка входа:** `index.handler`
   * **Таймаут:** `10 сек`
   * **Память:** `128 МБ` (достаточно минимальной)
2. В редакторе кода создайте 4 файла (просто скопируйте их содержимое из этой папки):
   * `package.json`
   * `index.mjs`
   * `signer.mjs`
   * `emailTemplate.mjs`
3. Нажмите кнопку **«Сохранить изменения»**.

---

### Шаг 3. Установка переменных окружения
В настройках функции перейдите в раздел **«Переменные окружения»** и добавьте 5 переменных:

| Переменная | Значение | Описание |
|---|---|---|
| `SMTP_HOST` | `smtp.spaceweb.ru` | Адрес почтового сервера SpaceWeb |
| `SMTP_PORT` | `465` | Порт SMTP с защитой SSL |
| `SMTP_USER` | `info@gridika.ru` | Ваш ящик отправителя |
| `SMTP_PASS` | `Ваш_Пароль` | Пароль от почты `info@gridika.ru` |
| `PRIVATE_KEY_JWK` | *(скопировать из `apps/fx/.license/private.jwk`)* | Секретный мастер-ключ подписи (весь текст в одну строку) |

Нажмите **«Сохранить изменения»**.

---

### Шаг 4. Сделать функцию публичной и получить Webhook URL
1. Вверху страницы функции включите тумблер **«Публичная функция»** (Public function).
2. Скопируйте **«Ссылку для вызова»**. Она имеет вид:
   ```text
   https://functions.yandexcloud.net/d4e123456789abcdef
   ```
3. Это и есть ваш **Webhook URL**!

---

## 💳 Подключение к ЮKassa

1. В личном кабинете [ЮKassa](https://yookassa.ru) перейдите в **Настройки** → **Интеграция** → **HTTP-уведомления** (Webhooks).
2. В поле **«URL для уведомлений»** вставьте ссылку из Шага 4.
3. Отметьте событие: **`payment.succeeded`** (Успешная оплата).
4. Нажмите **Сохранить**.

### Как передавать данные заказа при создании платежа:
При создании платежа в ЮKassa (через виджет, ссылку или API) в поле `metadata` достаточно передать:
```json
{
  "metadata": {
    "product": "qr-card",
    "domain": "site-клиента.ru",
    "name": "Иван Смирнов",
    "email": "buyer@client.ru",
    "cfg": "<базовый_хэш_настроек>"
  }
}
```
Как только клиент оплатит, ЮKassa вызовет функцию, и покупатель в течение 2-3 секунд получит письмо с готовым кодом и ключом!

## 🧪 Локальное тестирование

Вы можете протестировать работу функции на своём компьютере:
```bash
# Тест без отправки реального письма (симуляция):
node packages/billing-webhook/test-local.mjs my-email@domain.ru

# Тест с реальной отправкой письма через ваш SMTP (укажите пароль):
$env:SMTP_PASS="ваш_пароль"; node packages/billing-webhook/test-local.mjs my-email@domain.ru --send
```
