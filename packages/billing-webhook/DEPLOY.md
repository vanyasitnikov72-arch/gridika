# Развёртывание платёжного бэкенда Gridika (Yandex Cloud Functions)

Этот сервис принимает оплату от покупателей через ЮKassa, криптографически подписывает ссылки на готовый код (`/thanks#order=...&items=...&sig=...`), отправляет адаптивные HTML-письма с чеком через SpaceWeb SMTP и сохраняет заказы для админки (`/admin`).

---

## 🚀 Пошаговое развёртывание за 3 минуты

### Шаг 1. Создание функции в Яндекс Облаке
1. Войдите в консоль: [console.yandex.cloud](https://console.yandex.cloud).
2. В каталоге выберите сервис **Cloud Functions** (Бессерверные функции).
3. Нажмите **«Создать функцию»**:
   - **Имя:** `gridika-orders`
   - Нажмите **«Создать»**.

---

### Шаг 2. Загрузка кода
1. В блоке **«Среда выполнения»** выберите:
   - **Среда:** `Node.js 20` или `Node.js 18`
   - **Точка входа:** `index.handler`
   - **Таймаут:** `10 сек`
   - **Память:** `128 МБ`
2. Загрузите файлы из папки `packages/billing-webhook/`:
   - `package.json`
   - `index.mjs`
   - `signer.mjs`
   - `codeCompiler.mjs` *(серверный компилятор чистого кода без водяных знаков)*
   - `emailTemplate.mjs`
   - `pricing.mjs`
   - `db.mjs`
3. Нажмите **«Сохранить изменения»**.

---

### Шаг 3. Переменные окружения функции
В разделе **«Переменные окружения»** добавьте:

| Переменная | Пример значения | Назначение |
|---|---|---|
| `PRIVATE_KEY_JWK` | *(скопировать из `apps/fx/.license/private.jwk`)* | Секретный мастер-ключ ECDSA P-256 для подписи ссылок заказов |
| `SMTP_HOST` | `smtp.spaceweb.ru` | Адрес почтового сервера SpaceWeb |
| `SMTP_PORT` | `465` | Порт SMTP (SSL) |
| `SMTP_USER` | `info@gridika.ru` | Почта отправителя |
| `SMTP_PASS` | `Ваш_Пароль` | Пароль от почты `info@gridika.ru` |
| `ADMIN_SECRET` | `gridika2026` | Пароль для доступа админки к заказам |
| `YOOKASSA_SHOP_ID` | `123456` | Идентификатор магазина в ЮKassa |
| `YOOKASSA_SECRET_KEY` | `live_...` | Секретный ключ API в ЮKassa |
| `TELEGRAM_BOT_TOKEN` | *(опционально)* | Токен бота для мгновенных уведомлений о продажах |
| `TELEGRAM_CHAT_ID` | *(опционально)* | Ваш Chat ID в Telegram |

Нажмите **«Сохранить изменения»**.

---

### Шаг 4. Публичный доступ и получение Webhook URL
1. Вверху страницы функции включите тумблер **«Публичная функция»** (Public function).
2. Скопируйте **«Ссылку для вызова»**:
   ```text
   https://functions.yandexcloud.net/d4e...
   ```

---

### Шаг 5. Настройка вебхука в ЮKassa
1. В личном кабинете [ЮKassa](https://yookassa.ru) перейдите в **Интеграция** → **HTTP-уведомления**.
2. В поле **«URL для уведомлений»** укажите ссылку из Шага 4.
3. Отметьте событие: **`payment.succeeded`** (Успешная оплата).
4. Сохраните.

---

### Шаг 6. Инициализация базы данных (опционально)
Если используется Yandex Database (YDB) или Managed PostgreSQL, выполните скрипт [schema.sql](./schema.sql) в SQL-консоли базы данных для создания таблиц `orders` и `order_events`.
